# Сезонная корректировка: блокноты, модуль и данные

Открытый учебный и рабочий набор по сезонной корректировке временных рядов: от того, что такое
сезонность, до готового шаблона, в который подставляется свой показатель.

Всё работает на обычных файлах Excel в этой же папке — ни базы данных, ни настройки окружения не
требуется. Блокноты двуязычные: язык переключается одной строкой `LANG = "ru"` или `LANG = "en"`.

**Русский** · [English](README.en.md)

## Что в репозитории

| Файл | Что это |
|---|---|
| `x13_seasonal_full_pgh.ipynb` | Полный разбор: ~160 ячеек. Что такое сезонность, как её измерять, эволюция методов от Census Method I (1954) до X-13ARIMA-SEATS, сравнение с TRAMO/SEATS и JDemetra+, методы вне этой линии (STL, MSTL, TBATS, Prophet, UCM, вейвлеты), прикладные метрики. Каждое утверждение проверяется кодом на данных, где правильный ответ известен заранее. |
| `x13_seasonal_short_pgh.ipynb` | Обзор за час: те же идеи без выводов формул и без экспериментов. Хорошая точка входа. |
| `indicator_template_pgh.ipynb` | Рабочий шаблон для своего ряда. Копируется на каждый новый показатель; после каждого шага печатает проверку, согласуется ли ваше решение с данными. Настройки сохраняются в JSON рядом с блокнотом. |
| `seasonal_toolbox.py` | Модуль: около 160 функций. Загрузка данных, диагностика сезонности, календарные регрессоры, поиск выбросов, пять реализаций декомпозиции, обёртка над настоящим X-13, прикладные метрики и графики. |
| `seasonal_adjustment_ru.pdf` | Презентация, 32 слайда. |
| `seasonal_adjustment_en.pdf` | То же по-английски. |
| `RU_M2_M_CB.xlsx` | Пример данных: денежная масса M2, Банк России, с 1992 года. |
| `RU_TDAYSWKPC_M_GV.xlsx` | Производственный календарь России: рабочие дни по месяцам. |
| `requirements.txt` | Зависимости. |
| [`LICENSE`](LICENSE) | MIT для кода, CC BY 4.0 для материалов. |
| [`CITATION.cff`](CITATION.cff) | Данные для кнопки «Cite this repository» на GitHub. |

Формат данных простой: два столбца, `Date` и `Value`, даты на конец периода. Свои ряды кладите
рядом в таком же виде.

## Бинарник X-13ARIMA-SEATS: скачивается отдельно

В репозитории его **нет** и быть не может: это отдельная программа Бюро переписи населения США со
своими условиями распространения. Без неё всё работает — блокноты используют встроенные
реализации, а разделы, требующие настоящего движка, аккуратно пропускаются с сообщением.

Но для публикуемых цифр нужен именно официальный бинарник. На денежной массе M2 встроенные
реализации отличаются от оценки Банка России на 0,3–0,6%, официальный движок — на 0,3%. Разрыв
невелик на этом ряде, но на другом может оказаться больше, а официальный движок воспроизводит
методику, принятую статистическими службами.

**1. Скачайте** с сайта Бюро переписи: https://www.census.gov/data/software/x13as.html

Выберите сборку под свою систему. Нужен исполняемый файл, обычно он называется `x13as` (Linux,
macOS) или `x13as.exe` (Windows).

**2. Разрешите запуск** (Linux, macOS):

```bash
chmod +x /путь/к/x13as
```

На macOS система может заблокировать неподписанную программу. Тогда: Системные настройки →
Конфиденциальность и безопасность → рядом с сообщением о блокировке нажать «Разрешить», либо

```bash
xattr -d com.apple.quarantine /путь/к/x13as
```

**3. Пропишите путь в переменную окружения** `PATH_X13`. Блокноты читают её сами.

Linux и macOS — добавьте в `~/.zshrc` или `~/.bashrc`:

```bash
export PATH_X13="/usr/local/bin/x13as"
```

Windows — в PowerShell один раз:

```powershell
[Environment]::SetEnvironmentVariable("PATH_X13", "C:\x13as\x13as.exe", "User")
```

Либо, если не хочется трогать окружение, прямо в блокноте:

```python
sx.X13_BIN = "/путь/к/x13as"
```

**4. Проверьте.** В первой ячейке блокнота должно появиться имя файла, а не «не найден»:

```python
import seasonal_toolbox as sx
print(sx.X13_BIN, sx.x13_available())
```

## С чего начать

Если тема новая — `x13_seasonal_short_pgh.ipynb`, примерно час.

Если нужно разобраться по-настоящему — `x13_seasonal_full_pgh.ipynb`. Он самодостаточен: каждое
утверждение проверяется кодом, а данные синтетические, с заранее известным правильным ответом,
поэтому видно не только «метод работает», но и насколько.

Если нужно посчитать свой ряд — `indicator_template_pgh.ipynb`. Положите файл с данными рядом,
поменяйте настройки в первой ячейке и запустите целиком.

## Что важно знать до того, как применять

**Сезонная корректировка — не фильтр, а набор решений.** Логарифмировать или нет, учитывать
календарь или нет, что считать выбросом, каким методом раскладывать. Эти решения влияют на
результат сильнее, чем выбор между X-11 и SEATS, и принимаются человеком, а не программой.

**Край ряда всегда ненадёжен.** Последние месяцы оцениваются несимметричным фильтром и будут
пересмотрены с приходом новых данных. Это свойство метода, а не ошибка.

**Встроенные реализации в модуле — учебные.** Они повторяют логику X-11, SEATS и TRAMO, но проще
официальных. Для понимания этого достаточно, для публикуемых цифр — нет.
